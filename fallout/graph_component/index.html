How to read this graph

Arrows follow source → fact → summary. SUPPORTED_BY means source supports fact; COMPOSED_OF means fact contributes to summary. Each horizontal # reference identifies one edge in Relationships, which lists its full endpoints, type and state.

Dashed edges are retained but inactive. Amber outlines show a computed withdrawal preview; mint shows the entity being inspected. Inspection never changes the preview target. Ordinary invalid or revoked nodes stay neutral. Red is reserved for mismatches supplied by the verifier.

Select a node to reveal relationship lane names; select a fact to reveal its support counts. Shared support lists retained sources and counts active edges, not a verification verdict. Tab to a node; Enter or Space inspects it. Graph opens at native text size. Fit and zoom may shrink labels; scroll to pan when zoomed or viewing a large graph.
